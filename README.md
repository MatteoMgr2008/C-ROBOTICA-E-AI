## 🇮🇹 Italiano

### 📖 Descrizione

Raccolta di esercizi in **linguaggio C** svolti in classe per la materia scolastica **Robotica e AI**. Si tratta di primi esercizi introduttivi sull'output a schermo con `printf()`, commentati in italiano.

### 📂 Contenuto

Tutti i file si trovano nella cartella **`Esercizi in classe/`**:

| File | Descrizione |
|------|-------------|
| `Es. 1 (hello world).c` | Il classico programma che stampa `Hello, World!` |
| `Es. 2 (come stampare una striga di testo).c` | Stampa una stringa di testo con `printf()` |
| `Es. 3 (come andare a capo in una stringa di testo).c` | Usa il carattere `\n` per andare a capo all'interno di una stringa |

### 🛠️ Tecnologie

- **Linguaggio:** C (solo la libreria standard `stdio.h`)

### ▶️ Come compilare ed eseguire

**Requisiti:** un compilatore C, ad esempio `gcc`.

Dalla cartella `Esercizi in classe`, ad esempio per il primo esercizio:

```bash
gcc "Es. 1 (hello world).c" -o es1
./es1
```

Su Windows l'eseguibile generato è `es1.exe` (si avvia con `.\es1.exe`). Lo stesso procedimento vale per gli altri esercizi.

## 🇬🇧 English

### 📖 Description

A collection of **C language** exercises done in class for the school subject **Robotics and AI** (*Robotica e AI*). These are introductory exercises on printing output to the screen with `printf()`, with comments written in Italian.

### 📂 Contents

All files are located in the **`Esercizi in classe/`** ("class exercises") folder:

| File | Description |
|------|-------------|
| `Es. 1 (hello world).c` | The classic program that prints `Hello, World!` |
| `Es. 2 (come stampare una striga di testo).c` | Prints a text string with `printf()` |
| `Es. 3 (come andare a capo in una stringa di testo).c` | Uses the `\n` character to start a new line inside a string |

### 🛠️ Technologies

- **Language:** C (standard library `stdio.h` only)

### ▶️ How to compile and run

**Requirements:** a C compiler, for example `gcc`.

From the `Esercizi in classe` folder, for example for the first exercise:

```bash
gcc "Es. 1 (hello world).c" -o es1
./es1
```

On Windows the generated executable is `es1.exe` (run it with `.\es1.exe`). The same steps apply to the other exercises.
